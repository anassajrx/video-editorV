# Reference edit: measured analysis

Source: `example.mp4` (user's Drive), 42.9s, 720x1280 vertical, 30fps, 48kHz.
Contact sheet (1 frame/sec): `reference-contact-sheet.png`. Key frames: `reference-key-frames.png`.

## Measured
- **Loudness:** -14.1 LUFS integrated, LRA 3.2 LU (very compressed, consistent voice).
- **Dead air:** no silence > 0.25s at -35dB. Every pause is cut.
- **Speech rate:** ~167 words / 42.9s ≈ **3.9 words/sec**.
- **Shot:** a single locked-off talking head (chest-up, mic in frame). Cuts are jump cuts on the same framing; no B-roll footage, just graphics.
- **Graphic density:** ~10 distinct graphic moments in 43s, one every ~4s.

## Look
- Background: dark navy/blue gradient wall (#2c3055 → #050309), green plants for color contrast. Cool overall grade, skin kept natural.
- Accent: violet/purple glow (cards, avatar ring, timeline pin), gold for the premium "Blueprint" card.
- Captions sit at chest/mic level (~45–55% height), center, word-by-word.
- **Mixed typography:** big bold geometric sans for key words, small light sans for filler, italic script/serif for emotional words, all stacked and overlapping in one block ("Omar *in a* was stuck 9-5 *Job* *that he* hated").
- B&W desaturation on the line "I don't think I'm good enough to post yet", with the key words colored purple.

## Graphics used (in order)
1. Timeline bar at the bottom (9-5 → Beginner editor → 2k/mo) with an avatar pin that moves along it.
2. Profile bubble (glowing ring, name) with sparkle bullets: "Joined UE with basic skills", "9-5 with little time to learn".
3. Two glowing glass cards stacked: "Cinematic Short-Film", "Minimal Animations".
4. Gold premium card: "$2,000/mo Editor Blueprint".
5. B&W doubt moment.
6. Tweet/X post screenshots as proof, with the post's animation playing inside.

## Script structure
Result hook → person intro → struggle → skill-building → doubt → forced turning point → result with proof → CTA ("comment the word X and I'll send you the blueprint").
